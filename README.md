# PRITIOT Anti-Cheat Website

A framework-free, modern dark landing page inspired by the supplied reference.

## Run it
Open `index.html` in a browser, or serve the folder with any static web server.

## Customize
- Change the anticheat name in `index.html`.
- Replace the Discord URLs with your real invite.
- Edit feature cards and copy in `index.html`.
- Tweak the visual system in `styles.css`.

No backend or build step is required.
